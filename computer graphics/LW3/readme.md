# 1. Пошаговый (инкрементальный) алгоритм рисования линии

> Идея
> Мы выбираем маленький шаг по оси x (обычно 1 пиксель), вычисляем коэффициент наклона линии и каждый раз прибавляем его для получения нового y.

Шаги

x = x1, y = y1

На каждом шаге:
выводим пиксель (x, round(y))
> x = x + 1

> y = y + m

# 2. ЦДА (DDA — Digital Differential Analyzer)
По сути — улучшенная версия пошагового алгоритма. Делает то же самое, но нормализует шаг так, чтобы не было пропуска пикселей.

(x1, y1), (x2, y2)

∆x = x2 – x1

∆y = y2 – y1

steps = max(|∆x|, |∆y|)

> dx = ∆x / steps

> dy = ∆y / steps

> x += dx

> y += dy

# 3. Брезенхем (линия)

Самый эффективный классический алгоритм—использует только целые числа.

Шаги

1. x = x1, y = y1

2. error = 2·∆y – ∆x

На каждом шаге:

- Нарисовать пиксель (x, y)

- Если error ≥ 0:

        y += 1

        error += 2*(∆y – ∆x)

- иначе:

        error += 2·∆y

        x += 1

# Вывод

Рассмотренные алгоритмы представляют разные уровни качества и производительности при растровом построении примитивов.

Пошаговый (инкрементальный) алгоритм — самый простой, но неэффективный.
Он использует вещественные числа, накапливает ошибки округления и плохо работает для крутых линий. Этот метод больше учебный, чем практический.

Алгоритм ЦДА (DDA) — улучшение пошагового метода.
Он делает равномерные приращения по x и y, поэтому линии получаются более ровными. Однако он по-прежнему опирается на вычисления с плавающей точкой, что снижает скорость.

Алгоритм Брезенхема для линии — высокоэффективный, целочисленный алгоритм.
Он не использует вещественных чисел, работает быстро и точно. Ошибка контролируется пошагово, поэтому линия получается максимально близкой к идеальной. Это самый распространённый алгоритм рисования линий в растровой графике.

Алгоритм Брезенхема для окружности — развитие той же идеи, но с учётом симметрии окружности.
Он вычисляет точки только в одной восьмой окружности и отражает их, что минимизирует вычисления. Полностью целочисленный и очень быстрый, обеспечивает высокое качество растровой окружности.
