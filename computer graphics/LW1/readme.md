# Конвертер цветовых моделей (CMYK-RGB-HLS)

### 1. RGB (Red, Green, Blue)

*   **Принцип:** Аддитивная модель (от англ. *add* — добавлять). Цвета получаются путем смешения световых лучей. Изначально мы имеем черный экран (отсутствие света), и добавляя красный, зеленый и синий свет разной интенсивности, мы получаем весь спектр. Смешение всех трех цветов на максимальной яркости дает белый цвет.
*   **Назначение:** Отображение изображений на экранах: мониторы, телевизоры, экраны смартфонов, проекторы. Все, что излучает свет.
*   **Диапазон значений:** **0** - **255** 

### 2. CMYK (Cyan, Magenta, Yellow, Key/Black)

*   **Принцип:** Субтрактивная модель (от англ. *subtract* — вычитать). Цвета получаются путем смешения красок, которые поглощают (вычитают) определенные части светового спектра, отражающегося от белой бумаги. Смешение голубой, пурпурной и желтой красок в теории должно давать черный, но на практике получается грязно-коричневый цвет. Поэтому для получения глубокого черного и экономии красок был добавлен четвертый, ключевой цвет — черный (Black).
*   **Назначение:** Полиграфия, печать на принтерах. Все, что связано с нанесением краски на физическую поверхность.
*   **Диапазон значений:** **0** - **100** 

### 3. HLS (Hue, Lightness, Saturation)

*   **Принцип:** Цилиндрическая модель, которая описывает цвет более интуитивно для человеческого восприятия.
    *   **Hue (Цветовой тон):** Сам цвет как таковой (красный, оранжевый, сине-зеленый и т.д.). Представлен в виде угла на цветовом круге.
    *   **Lightness (Освещенность/Яркость):** Насколько цвет светлый или темный. 0% — это всегда черный, 100% — всегда белый, а 50% — это самый "чистый" и насыщенный оттенок.
    *   **Saturation (Насыщенность):** Интенсивность, "сочность" или "чистота" цвета. 0% — это оттенки серого (от черного до белого), 100% — максимально яркий и насыщенный цвет.
*   **Назначение:** Графические редакторы, дизайн-инструменты, палитры выбора цвета. Эта модель очень удобна, когда нужно сделать цвет "чуть светлее" или "менее насыщенным".
*   **Диапазон значений:**
    *   **H (Тон):** от **0°** до **360°**
    *   **L (Освещенность):** от **0%** до **100%**
    *   **S (Насыщенность):** от **0%** до **100%**

### CMYK в RGB

Сначала значения CMYK нормализуются из диапазона [0, 100] в [0, 1].
```
R = 255 * (1 - C) * (1 - K)
G = 255 * (1 - M) * (1 - K)
B = 255 * (1 - Y) * (1 - K)
```

### RGB в CMYK

Сначала значения RGB нормализуются из диапазона [0, 255] в [0, 1].
```
// Если R, G, B равны 0, то цвет - черный
Если (R, G, B) == (0, 0, 0), то CMYK = (0, 0, 0, 100)

// В противном случае:
K = 1 - max(R, G, B)
C = (1 - R - K) / (1 - K)
M = (1 - G - K) / (1 - K)
Y = (1 - B - K) / (1 - K)
```
